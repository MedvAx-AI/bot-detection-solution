Признаки рассчитаны для каждой cookie_id только по событиям внутри её суточного окна. Использованы количество и доли действий, паузы между событиями, активность по времени, разнообразие объявлений, категорий, локаций и запросов, возраст куки, платформа и User-Agent. Для курсора рассчитаны размах координат, длины перемещений, повторяемость и смена направления, корреляция координат и доля событий с координатами. Отдельная модель использует журнал после удаления полностью одинаковых строк событий.

Итоговый score — взвешенное среднее прогнозов четырёх CatBoost: основные признаки — 12,5%, основные признаки с перемещениями курсора — 37,5%, признаки после удаления дубликатов — 25%, расширенные признаки курсора и устройства — 25%. Все модели обучены на размеченной выборке, random_seed=42; идентификатор cookie_id признаком не является.

Валидация проведена по времени: 11–13, 14–16 и 17–19 апреля, с обучением только на предыдущих днях. Precision при Recall ≥ 70% составил 0,6731; 0,7709; 0,7943, среднее — 0,7461. Сравнивались Random Forest, ExtraTrees, LightGBM, HistGradientBoosting и CatBoost, отбор признаков, признаки последовательности и времени, обработка дубликатов и усреднение моделей. Значения относятся к локальной валидации. Использованы локальные открытые библиотеки NumPy, pandas, scikit-learn и CatBoost; Python 3.13.13, зависимости зафиксированы в requirements.txt.
