# Дополнительные эксперименты

Проверены XGBoost глубины 3 и 5, CatBoost с большим весом свежих дней (период полураспада 7 дней), отдельные CatBoost для веба и мобильного трафика, а также лексические свойства поисковых запросов. Проверочные периоды и размеченные данные совпадают с описанными в основном README.

```bash
python -m pip install -r experiments/requirements.txt
python experiments/improve.py
```

Скрипт самостоятельно строит признаки и опорные прогнозы, если их нет в локальном `work/experiments`. Кэш признаков и опорных прогнозов связан с SHA-256 исходных файлов; он не публикуется. Все новые модели переобучаются при запуске. Результаты пишутся в `work/experiments/results.csv`.

Публичные таблицы `results.csv` и `query_results.csv` содержат фактически полученные метрики. В колонке `weight` указана доля новой модели; остальная доля приходится на общий ансамбль. Строки с `weight=0` — опорный результат. `average_precision` является отдельной диагностической метрикой.

Выбрана смесь с 15% прогноза моделей по платформам. Она улучшила основную метрику на всех трёх временных отрезках. XGBoost, взвешивание по свежести и свойства текста запросов не дали сопоставимого устойчивого улучшения. Периоды используются для выбора модели: это локальный подбор, а не независимая оценка кандидата на скрытом тесте.

Для самостоятельного повторения признаков запросов используется `query_features.py`; результаты их проверки не включены в итоговое предсказание. После `improve.py` выполните `python experiments/evaluate_queries.py`: скрипт использует созданный локальный кэш основных признаков и опорных прогнозов, рассчитывает признаки запросов заново и повторяет три временные проверки.
